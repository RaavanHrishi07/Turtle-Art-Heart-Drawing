# Turtle Art & Heart Drawing

A colourful drawing application built with Python Turtle. It creates a layered pink and red heart on a dark background, decorated with stars and text.

## Features

- Draws a layered heart using mathematical curves.
- Creates a starry night-style background.
- Adds decorative headings and a message.
- Uses different colours for the heart layers.
- Runs as a desktop graphics application using Python Turtle.

## Technologies Used

- Python 3
- Turtle
- Math
- Random

## Requirements

- Python 3.11 or later
- Tkinter/Turtle support included with your Python installation

No external Python packages are required.

## How to Run

1. Clone the repository:

       git clone https://github.com/RaavanHrishi07/Turtle-Art-Heart-Drawing.git

2. Open the project folder:

       cd Turtle-Art-Heart-Drawing

3. Run the application:

       python main.py

## How It Works

The program uses mathematical parametric equations to create the heart shape. Multiple heart layers are drawn in different colours to create a decorative effect. Randomly positioned stars and text complete the artwork.
