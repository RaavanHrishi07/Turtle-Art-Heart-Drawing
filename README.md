# Turtle Art & Heart Drawing

A colourful animated drawing application built with Python Turtle. It creates a beautiful layered pink and red heart on a dark background, decorated with stars and text. You can customise the heart and background colours and save your finished artwork as a PNG image.

## Features

- Draws a layered heart using mathematical curves.
- Animates the heart drawing process.
- Creates a starry night-style background.
- Adds decorative headings and messages.
- Allows custom heart and background colours using colour pickers.
- Saves the finished artwork as a PNG image.
- Provides an interactive desktop graphics experience.

## Technologies Used

- Python 3
- Turtle
- Tkinter
- Math
- Random
- Pillow

## Requirements

- Python 3.11 or later
- Tkinter/Turtle support included with your Python installation
- Pillow library for image export

Install the required external package:

    python -m pip install Pillow

## How to Run

1. Clone the repository:

       git clone https://github.com/RaavanHrishi07/Turtle-Art-Heart-Drawing.git

2. Open the project folder:

       cd Turtle-Art-Heart-Drawing

3. Install the dependency:

       python -m pip install Pillow

4. Run the application:

       python main.py

5. Choose your preferred heart and background colours when prompted.
6. Wait for the drawing animation to finish.
7. Click **SAVE ARTWORK** and choose where to save the PNG image.

## How It Works

The program uses mathematical parametric equations to create the heart shape. Multiple heart layers are drawn in different colours to produce a decorative effect. Randomly positioned stars and text complete the artwork.

The drawing is animated using Python Turtle. Tkinter colour pickers let users customise the heart and background. The save feature exports the finished artwork as a PNG image.
